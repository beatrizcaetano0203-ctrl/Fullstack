### Grid (Duas ou  Dimensões)

https://cssgridgarden.com/

```css
<html>  
<head>  
<style>  
.container {  display: grid;  
  grid-template-columns: auto auto auto;  
  background-color: dodgerblue;  
  padding: 10px;}  
.container div {  background-color: #f1f1f1;  
  border: 1px solid black;  
  padding: 10px;  
  font-size: 30px;  
  text-align: center;}  
</style>  
</head>  
<body>  
  
<div class="container">  
  <div>1</div>  
  <div>2</div>  
  <div>3</div>  
  <div>4</div>  
  <div>5</div>  
</div>  
  
</body>  
</html>
```
