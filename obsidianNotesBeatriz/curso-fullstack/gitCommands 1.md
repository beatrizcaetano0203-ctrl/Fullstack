Comandos relacionados a repositorios:


git init: Cria um repositório Git novo na pasta.
git clone: Baixa um repositório da internet (exemplo: git clone [url]).
git status: Mostra o estado dos arquivos modificados.
git add: Prepara os arquivos para salvar (exemplo: git add .).
git commit: Salva as alterações preparadas com uma mensagem (exemplo: git commit -m "mensagem").
git push -u origin <nome-da-branch> (envia seus códigos pela primeira vez e define a branch padrão)
git push: Envia seus salvamentos para o site remoto.git pull: Baixa as novidades do site remoto para o seu computador.
git fetch (baixa as novidades do servidor, mas não mexe no seu código local)
git pull (baixa as novidades do servidor e atualiza seu código local)
